# 要件定義書（X風SNS）

## 1. 概要

### 1.1 目的
短文投稿を中心とした、X（旧Twitter）風のSNSを開発する。

### 1.2 スコープ
- 対象：Webアプリケーション（PC・モバイルブラウザ）
- 対象外（初期リリース）：ネイティブアプリ、広告配信、ダイレクトメッセージ、動画投稿

### 1.3 想定ユーザー
| 区分 | 説明 |
|------|------|
| 一般ユーザー | 投稿・閲覧・フォローを行う |
| 未ログイン閲覧者 | 公開投稿の閲覧のみ可能 |
| 管理者 | 通報対応・ユーザー停止を行う |

## 2. 機能要件

優先度：**必須**＝初期リリースに含む / **推奨**＝できれば含む / **将来**＝次フェーズ

### 2.1 アカウント
| ID | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| A-01 | 新規登録 | メールアドレスとパスワードで登録する | 必須 |
| A-02 | ログイン／ログアウト | セッションを維持できる | 必須 |
| A-03 | パスワード再設定 | メールのリンクから再設定する | 必須 |
| A-04 | プロフィール編集 | 表示名、ユーザーID、自己紹介、アイコン画像 | 必須 |
| A-05 | アカウント削除 | 本人の操作で投稿を含めて削除できる | 必須 |
| A-06 | 外部認証 | Google等でのログイン | 将来 |

### 2.2 投稿
| ID | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| P-01 | 投稿作成 | 最大140文字（※要確認）のテキスト投稿 | 必須 |
| P-02 | 画像添付 | 1投稿につき最大4枚 | 推奨 |
| P-03 | 投稿削除 | 自分の投稿のみ削除できる | 必須 |
| P-04 | 返信 | 他の投稿にぶら下げて返信する | 必須 |
| P-05 | 引用・リポスト | 他の投稿を再投稿、またはコメント付きで引用する | 推奨 |
| P-06 | 投稿詳細 | 投稿と返信スレッドを表示する | 必須 |
| P-07 | 投稿編集 | 投稿後の編集 | 将来 |

### 2.3 タイムライン
| ID | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| T-01 | ホームタイムライン | フォロー中ユーザーの投稿を新しい順に表示する | 必須 |
| T-02 | 全体タイムライン | 全ユーザーの公開投稿を新しい順に表示する | 推奨 |
| T-03 | ページング | 無限スクロールまたは「もっと見る」で追加取得する | 必須 |
| T-04 | おすすめ表示 | アルゴリズムによる並び替え | 将来 |

### 2.4 ソーシャル機能
| ID | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| S-01 | フォロー／解除 | 他ユーザーをフォロー・解除できる | 必須 |
| S-02 | フォロー／フォロワー一覧 | 一覧を表示する | 必須 |
| S-03 | いいね | 投稿へのいいねとその取り消し | 必須 |
| S-04 | ブックマーク | 自分だけが見られる保存機能 | 推奨 |
| S-05 | ブロック／ミュート | 特定ユーザーの投稿を非表示にする | 推奨 |
| S-06 | 非公開アカウント | フォロワーのみに投稿を公開する | 将来 |

### 2.5 検索・通知
| ID | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| N-01 | ユーザー検索 | 表示名・ユーザーIDで検索する | 必須 |
| N-02 | 投稿検索 | キーワードで投稿を検索する | 推奨 |
| N-03 | ハッシュタグ | `#タグ` から一覧へ遷移できる | 推奨 |
| N-04 | メンション | `@ユーザーID` で相手に通知する | 推奨 |
| N-05 | アプリ内通知 | フォロー、いいね、返信、メンションを通知する | 必須 |
| N-06 | プッシュ／メール通知 | アプリ外への通知 | 将来 |

### 2.6 管理・安全対策
| ID | 機能 | 内容 | 優先度 |
|----|------|------|--------|
| M-01 | 通報 | 投稿・ユーザーを通報できる | 必須 |
| M-02 | 管理画面 | 通報一覧の確認、投稿削除、ユーザー停止 | 必須 |
| M-03 | 利用規約・プライバシーポリシー | 登録時に同意を取得する | 必須 |

## 3. 非機能要件

| 区分 | 要件 |
|------|------|
| 性能 | タイムライン表示は通常時2秒以内（※目標値、要確認） |
| 可用性 | 目標稼働率99%（※要確認） |
| セキュリティ | パスワードはハッシュ化して保存する（bcrypt / argon2）。通信はHTTPS。CSRF・XSS・SQLインジェクション対策を行う。ログイン試行とAPIにレート制限を設ける |
| プライバシー | 個人情報は必要最小限だけ保持する。アカウント削除時に関連データを削除する |
| 互換性 | 最新版のChrome / Safari / Edge / Firefoxで動作する |
| レスポンシブ | スマートフォンの画面幅（375px〜）に対応する |
| 保守性 | API仕様書を整備し、主要機能に自動テストを用意する |
| 画像 | 形式はJPEG / PNG / WebP、1枚あたり上限5MB（※要確認） |

## 5. 主なデータ

```
User      id, user_handle, display_name, email, password_hash, bio, avatar_url, created_at
Post      id, user_id, body, reply_to_id, repost_of_id, created_at, deleted_at
PostImage id, post_id, url, order
Follow    follower_id, followee_id, created_at
Like      user_id, post_id, created_at
Bookmark  user_id, post_id, created_at
Block     user_id, target_user_id, created_at
Notification id, user_id, type, actor_id, post_id, read_at, created_at
Report    id, reporter_id, target_type, target_id, reason, status, created_at
```

## 6. 技術構成（案）

このリポジトリの構成（`backend` / `frontend` / `api` / `documents`）に合わせる。

| 領域 | 案 |
|------|-----|
| フロントエンド | TypeScript + React + Vite（詳細は[アーキテクチャ.md](アーキテクチャ.md)） |
| バックエンド | Go（レイヤードアーキテクチャ、OpenAPI駆動。詳細は[アーキテクチャ.md](アーキテクチャ.md)） |
| データベース | PostgreSQL |
| 画像保存 | オブジェクトストレージ（S3 等） |
| 認証 | セッションまたはJWT |

## 7. 未決事項

- 投稿の文字数上限（140文字か、それ以上か）
- 公開範囲：誰でも閲覧できるか、ログイン必須か
- 運営形態：個人利用、クローズドなコミュニティ、一般公開のどれか
- 収益化の有無（広告・課金）
- 想定ユーザー数と、それに合わせたインフラ規模
- DM機能・動画投稿をいつ追加するか
- 不適切投稿への対応方針（目視確認か、自動検知を併用するか）
